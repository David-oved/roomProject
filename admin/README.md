# 🛡️ קונסולת המנהל — RoomMate Admin Console

אפליקציית דסקטופ שרצה **על המחשב של מנהל התוכנה בלבד**. היא נותנת תמונת
מצב מלאה על המערכת — מי עושה מה, באיזה חדר, מה נשבר, ומה המשתמשים אומרים
— ומאפשרת לפעול: לאשר, להתערב, לשלוח הודעה, לייצא דוח.

```
npm run admin        # מפעיל שרת + ממשק ופותח את הדפדפן
```

---

## למה זה לא חלק מהאפליקציה

באפליקציה הראשית, כל משתמש רואה רק את החדרים שלו — וכך גם צריך להיות.
מה שמונע ממנו לראות יותר הוא Security Rules, ולא הממשק. קונסולה שרצה
בדפדפן של משתמש הייתה חייבת הרשאת קריאה גורפת לכל העץ, וכל דלת כזו היא
דלת שאפשר לפרוץ.

לכן הקונסולה בנויה אחרת:

```
┌──────────────────────────┐        ┌─────────────────────────┐
│  ממשק (React, 127.0.0.1) │ ⇄ API  │ שרת מקומי (Node)        │
└──────────────────────────┘        │  firebase-admin SDK     │
                                    └───────────┬─────────────┘
                                                │ עוקף Rules
                                       ┌────────▼────────┐
                                       │  Firebase RTDB  │
                                       └─────────────────┘
```

מפתח ה-service account לעולם לא עוזב את המחשב שלי, והדפדפן מדבר רק עם
`127.0.0.1`.

## הרצה

### מצב הדגמה (ברירת מחדל, בלי חיבור לייצור)

```bash
npm run admin
```

בלי `service-account.json` הקונסולה עולה על נתוני הדגמה מלאים: חמישה
חדרים (בריא / בסיכון / נטוש), 14 משתמשים, קניות, מטלות, משוב והודעות.
כל הפעולות עובדות ונשמרות מקומית ב-`admin/.data/demo-db.json`.

### מול האמולטור המקומי (מומלץ לפיתוח)

נתונים אמיתיים של האפליקציה, בלי להחזיק מפתח ייצור על המחשב:

```bash
npm run emu                                  # טרמינל 1 — אמולטורים
npm run emu:seed                             # טרמינל 2 — זריעת נתונים
FIREBASE_DATABASE_EMULATOR_HOST=127.0.0.1:9000 \
GCLOUD_PROJECT=<project-id> npm run admin    # טרמינל 3 — הקונסולה
```

הקונסולה תעלה במצב חי ותציג "אמולטור מקומי" במסך המערכת. כך אפשר לבדוק
פעולות שכותבות לנתונים — אישור קנייה, מענה למשוב, ארכוב חדר — ולראות
את התוצאה באפליקציה עצמה, בלי סיכון.

### מצב חי (נתוני ייצור)

1. Firebase Console → ⚙️ Project settings → Service accounts →
   **Generate new private key**.
2. שמרו את הקובץ בשם `admin/service-account.json`
   (או הגדירו `ADMIN_SERVICE_ACCOUNT=/path/to/key.json`).
3. ודאו ש-`VITE_FB_DATABASE_URL` מוגדר ב-`.env.local` שבשורש.
4. `npm run admin`

> ‼️ `service-account.json` הוא **סוד אמיתי** — בניגוד ל-apiKey של הלקוח,
> הוא עוקף את כל ה-Security Rules. הוא נמצא ב-`.gitignore`, ואסור לו
> להיכנס ל-git, ל-Drive או ל-Slack.

### משתני סביבה

| משתנה | ברירת מחדל | תפקיד |
|---|---|---|
| `ADMIN_PORT` | `5190` | פורט שרת ה-API המקומי |
| `ADMIN_WEB_PORT` | `5199` | פורט שרת הפיתוח של הממשק |
| `ADMIN_SERVICE_ACCOUNT` | `admin/service-account.json` | נתיב למפתח |
| `ADMIN_DATABASE_URL` | `VITE_FB_DATABASE_URL` | כתובת ה-RTDB |

### פקודות

| פקודה | מה היא עושה |
|---|---|
| `npm run admin` | שרת + ממשק (Vite) + פתיחת דפדפן |
| `npm run admin:server` | שרת ה-API בלבד |
| `npm run admin:build` | בדיקת טיפוסים ובניית הממשק ל-`admin/dist` |
| `npm run admin:preview` | הרצת הגרסה הבנויה מהשרת המקומי בלבד |
| `npx vitest run tests/admin` | בדיקות מנוע הקונסולה |

## "רק אני" — שלוש שכבות גישה

1. **האזנה מקומית בלבד.** השרת מאזין ל-`127.0.0.1`. אין דרך להגיע אליו
   מהרשת, גם לא מאותה רשת Wi-Fi.
2. **בדיקת מקור.** כל בקשה נבדקת שהגיעה מלולאה מקומית ושה-`Host` הוא
   localhost — הגנה מפני DNS rebinding דרך דפדפן.
3. **טוקן מקומי.** נוצר פעם אחת ונשמר ב-`admin/.data/token` (הרשאות
   600). המשגר מזריק אותו לכתובת, הממשק שומר אותו ומנקה אותו מיד מה-URL.

איבדתם את הטוקן? הוא מודפס בטרמינל בכל הפעלה, ונמצא בקובץ.

## החלטות שכדאי להכיר

### הפיד נגזר מהנתונים, לא מיומן אירועים
RTDB מחזיק **מצב**, לא היסטוריה. כל אירוע בפיד נגזר מחותמת זמן של רשומה
קיימת (`item.reportedAt`, `purchase.createdAt`, `member.joinedAt`…).
היתרון: אי אפשר לאבד אירוע ואי אפשר לזייף אחד — מה שרואים הוא בדיוק מה
שקיים בבסיס הנתונים. המחיר: אין אירועי "צפה במסך", ומחיקה של רשומה מוחקת
גם את האירוע שלה.

### "אורך סשן" הוא הערכה — והממשק אומר את זה
אין SDK אנליטיקה ואין מעקב בדפדפן של המשתמשים. סשן מוגדר כאשכול פעולות
של אותו משתמש עם פער קטן מ-30 דקות. בכל מקום שבו המספר מוצג הוא מסומן
כהערכה, כי מספר שמתחזה למדויק גרוע ממספר שמודה שהוא לא.

### תוכן שיחות מטושטש עד לחיצה
הודעות צ׳אט של שותפים מופיעות בפיד כ"כתב הודעה", והתוכן מטושטש. לחיצה
מפורשת חושפת אותו. "לדעת שדובר" ו"לקרוא מה נאמר" הן שתי החלטות שונות,
וכלי שמערבב ביניהן הופך קריאת שיחות פרטיות לדבר שקורה בהיסח דעת.

### שום פעולה לא מוחקת נתונים
- **איפוס מאזנים** מסמן קניות מאושרות כ-`settled`. הקניות נשארות ביומן.
- **ארכוב חדר** מסמן `metadata/archivedAt`. שום ענף לא נמחק.
- לפני כל פעולה הרסנית נשמר גיבוי מלא של הצומת תחת
  `adminConsole/backups`, וכל פעולה נרשמת ב-`adminConsole/auditLog`
  (מי, מתי, על מה, ומה היה הערך הקודם).

### למה יש כאן עותק של מנוע הכספים
`admin/server/money.mjs` הוא עותק סמנטי של `src/lib/money.ts`, ולא ייבוא.
הקונסולה היא כלי **ניטור**: אם מחר תשתנה שיטת החישוב באפליקציה, אני רוצה
שהקונסולה תמשיך לחשב לפי הכלל שאני מכיר — ושהפער יתגלה, במקום שיוסתר על
ידי שימוש חוזר באותו קוד. הבדיקות ב-`tests/admin` נועלות את ההתנהגות.

### התראה נעלמת מעצמה
כל התראה נגזרת מהמצב הנוכחי. כשהבעיה נפתרת, ההתראה נעלמת בלי "סימון
כטופל". מה שנשמר הוא רק מתי ראיתי אותה לראשונה ואם ביטלתי אותה — כדי
ש"חדש מאז שיצאתי" יהיה מידע אמין.

## מבנה

```
admin/
├─ start.mjs              משגר: שרת + ממשק + פתיחת דפדפן
├─ vite.config.ts         בנייה נפרדת לגמרי מהאפליקציה (בלי PWA)
├─ server/
│  ├─ index.mjs           שרת HTTP, SSE, הגשת סטטי
│  ├─ auth.mjs            טוקן, לולאה מקומית, בדיקת Host
│  ├─ config.mjs          סביבה, מצב חי/הדגמה
│  ├─ db.mjs              שכבת נתונים: Admin SDK או זיכרון
│  ├─ seed.mjs            עולם ההדגמה
│  ├─ state.mjs           מטמון של כל הנגזרות + הודעה על שינוי
│  ├─ world.mjs           מודל העולם (משתמשים, חדרים, כספים)
│  ├─ activity.mjs        גזירת אירועים, פיד, צירי זמן
│  ├─ insights.mjs        התנהגות משתמשים ופלחים
│  ├─ roomHealth.mjs      ציון בריאות וזיהוי בעיות
│  ├─ alerts.mjs          טריגרים, שעות שקט
│  ├─ feedback.mjs        מיזוג משוב + מצב טיפול
│  ├─ messaging.mjs       קהלים, מעקב מסירה, שיחות
│  ├─ reports.mjs         דוחות וייצוא
│  ├─ actions.mjs         כל הכתיבות + יומן ביקורת + גיבויים
│  └─ api.mjs             טבלת הנתיבים
└─ web/src/               ממשק React (ראו docs/13-admin-console.md)
```

חוזה הנתונים מול אפליקציית המשתמשים מתועד ב-`docs/13-admin-console.md`.
